# V&Vテンプレートの使用方法

このディレクトリには新しいStudy、Case、実行マニフェスト、外部参照メタデータ、およびレビュー用文書の**ひな形**を収録しています。`examples/vv/`は具体的な値を持つ**使用例**、`tests/fixtures/`は自動テスト専用の**固定データ**、`vv_study/`は実際のV&V Studyの**設定・作業領域**です。

| ファイル | 用途 |
|---|---|
| `case.json` | Case定義を作成する際のひな形。架空のモデルID・仮パスを修正すること |
| `execution.json` | 一括実行マニフェストのひな形。対象Case等を明示すること |
| `study.json` | Study設定のひな形。解析条件・参照量の未設定値を確定すること |
| `reference.json` | 外部参照メタデータのひな形。出典・単位・不確かさを明示すること |
| `evaluation_report.md` | 13章評価報告書のひな形。工学的受容の自動認定ではない |
| `test_record.md` | Test ID別の個別試験記録ひな形 |
| `research/` | 文献・参照値・試験被覆を整理するCSVひな形 |

`study.json`の相対パス（例：`../docs/vv/plan.md`、`01_database/test_catalog.csv`）は、**コピー先をリポジトリ内の `vv_study/study.json` とした場合**を想定しています。新しい独立Studyディレクトリへコピーする場合は、計画書・カタログの位置に合わせてパスを修正してください。既存のレビュー済みStudy設定をテンプレートで上書きしないでください。

`plan.version` と `plan.sha256` は使用する正式な計画書に一致させてください。テンプレートの数値・文字列は工学的な承認を意味しません。正式な計画書 `../plan.md` の内容はこの整理では変更していません。
